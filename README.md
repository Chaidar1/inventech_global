# Inventech Global - Inventory Management System

Aplikasi manajemen inventaris **fullstack** yang dibangun menggunakan FastAPI (Backend) dan ReactJS (Frontend). Proyek ini dikembangkan sebagai bagian dari program magang di PT Cybers Blitz Nusantara.

## Tech Stack

- **Backend:** FastAPI, Python, SQLAlchemy
- **Frontend:** ReactJS, Axios, Tailwind CSS
- **Database:** MySQL
- **Tools:** Git, Postman, Figma

## Fitur Utama

- Dashboard interaktif untuk monitoring stok barang
- Manajemen data barang (CRUD)
- Manajemen data supplier
- Manajemen transaksi stok masuk/keluar
- Laporan inventaris
- Autentikasi pengguna

## Cara Menjalankan

### Prasyarat
- Python 3.9+
- Node.js 16+
- MySQL

### Backend
1. Masuk ke folder backend: `cd Backend`
2. Buat virtual environment: `python -m venv venv`
3. Aktifkan venv: `venv\Scripts\activate` (Windows)
4. Install dependensi: `pip install -r requirements.txt`
5. Konfigurasi database di file `.env`
6. Jalankan server: `uvicorn main:app --reload`

### Frontend
1. Masuk ke folder frontend: `cd Frontend`
2. Install dependensi: `npm install`
3. Jalankan: `npm run dev`
